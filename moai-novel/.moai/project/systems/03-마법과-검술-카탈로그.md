# Spell and Blade Arts — 마법·검술 분석

본작 리투니아 대륙의 *마법 35종 + 검술 35종* 카탈로그 + 각 스타일 정통 + 시전속도·위력·운용 매개·결합 정통.

본 문서의 목적 = *전투 시나리오의 다양성과 개연성 확보*. 등급 체계는 [`./06-군사-등급과-교리.md`](./06-군사-등급과-교리.md). 화폐·보석 정통은 [`../world/07-상업과-경제.md`](../world/07-상업과-경제.md).

## 1. 마법 시전속도 등급 정통

본작 정통상 *마법의 *써클 단계*가 *시전속도*를 결정한다. 같은 마법사도 *익숙한 마법은 단축·익숙하지 않은 마법은 느림*.

| 써클 단계 | 일반 시전 시간 | 본작 카엘 적용 (Ch1 P5 시점) |
|----------|---------------|------------------------------|
| 1써클 | 즉발~0.5초 | 즉발 (반복 시전 매개) |
| 2써클 | 0.5~1초 | 0.5초 이내 |
| 3써클 | 1초 이내 | **약 1초 이내** + *동시 시전·압축 응용 가능 (변칙 마검사 매개)* |
| 4써클 | 2~3초 | **약 2초** + *익숙·반복 가능* |
| 5써클 | 5~10초 | **수초 (대개 5~7초) — 쓰기 어렵지만 가능. 일부 익숙한 5써클만 안정 운용** |
| 6써클 | 10~20초 | (카엘 시전 불가 — Ch2 마력→내공으로 변환 후 시도) |
| 7써클 | 15~30초 | (대륙 정규 7써클 대마법사 영역) |
| 8써클 | 30~60초 | (호스반 8써클 시전 정점) |
| 9써클 | 60~720초 (8~12분 본격 광역) | (칼란 베르냐스 9써클 정점) |

### 마검사·앤트로퍼 변종의 *시전 단축 정통*

- **변칙 마검사** (카엘 Ch1 시기) = *3써클 이내 마법을 *압축 시전·동시 시전·검기 결합 매개*로 *1초 이내 다발 발사*
- **앤트로퍼 특전 마기** (카엘 Ch1 P5 직후) = *체외 마법 시전 외에 *전신 마기 회로*를 *체내에 흘려 신체 가속·내구·공격력 강화*. *마법 시전 자체는 단축 불가하나 *육체 보조의 즉발 효과*
- **공허검 호흡** (카엘 Ch2 P3 이후) = *마나 운용 안정성 향상 → 5써클 시전 시간 7~10초 → 5~7초로 단축 가능*

### 신성 마법의 *시전속도 특화*

- 신성 마법은 *써클 등급이 아닌 *신성 위계*로 측정 (대주교·주교·신부·수도사)
- *신성 마법 = 일반 마법 대비 시전시간 *1.5~2배* — 의식·기도 매개가 필요*
- 그러나 *위력 = 광역 회복·축복·결계 방어*로 *일반 공격 마법보다 *전장 지속성·생존성 우위*
- **본작 정통 — 카르샤 신성제국 정통조차 *시전속도 약점*이 본질**. *알레이언 6세 같은 신성검 운용자도 *신성 마법은 시전 시간 매개로 *전투 중 운용이 매우 제한적*

## 2. 마법 카탈로그 — *써클별 정리*

본 §의 정통 = *써클은 *합성 깊이*의 측정 단위*. *낮은 써클일수록 단일 원리 + 즉발·짧은 시전·작은 위력 + 적은 제약*. *높은 써클일수록 다중 원리 합성 + 시전 시간 + 큰 위력 + 본질적 제약 증가*.

각 마법 항목 = **마법명 + 원리 + 제약**의 3중 명시. 원리는 [`./01-마법-시스템.md`](./01-마법-시스템.md) §2 *A·B→C 결합 시전 정통*의 *감응→배열→고정의 합성 매개*에 일관.

### 1써클 (단일 원리·즉발~0.5초·10종)

> *단일 원소 + 단일 운용 = 1써클*. *합성 0*. 시전 시간 *즉발~0.5초*. 위력 단발·짧은 거리·미세 효과.

1. **바람의 화살 (Wind Arrow)**
   - 원리: *바람 압축 — 손끝의 마나를 *공기 압축 매개로 *얇은 칼날 형태로 발사*
   - 제약: *없음* (대륙 마법사 기초 기술)
2. **바람 손날 (Wind Hand)** ★ (사용자 정통 — 3써클에서 1써클로 이동)
   - 원리: *바람 압축 단일 — 손날 형태로 압축된 공기 띠를 *근접 베기 매개로 발사*. *합성 0의 직격*
   - 제약: *근접 1~2m*. 검과 합성 시 *검 자체에 마나 통전*은 운용자 기량 매개로 부가됨 (검 합성은 별도 기술)
3. **바람 폭발 (Wind Burst — 미세)** ★ (사용자 추가)
   - 원리: *순간적인 공기 압축 + 즉시 팽창 폭발 — 자기 손바닥 기준 반경 1~2m 단발 폭압*
   - 제약: *주변 공기 풍부 필요*. *진공·고지대 희박 영역 시전 약화*
4. **화염주먹 (Flame Fist)** ★ (사용자 추가)
   - 원리: *손에 순간 화염 발생 + 직접 폭발 직격 — 근접 격투 매개*. *압축 없이 즉발 폭발*
   - 제약: *근접 1m 이내 + 자기 손 접촉 시점 폭발 — 자기 손도 미세 화상 위험*. 비 올 때 시전 약화
5. **빙판 보법 (Ice Step)**
   - 원리: *발바닥 마나로 *공기 중 미세 수분 즉시 결정화 → 빙판 형성*
   - 제약: *건조한 사막·고온 영역에서는 미세 수분 부족으로 시전 불가*
6. **전기 충격 (Static Shock)**
   - 원리: *접촉 마나의 *정전 응축 + 즉방출* — 작은 마비 효과
   - 제약: *반드시 *피부 또는 금속 접촉*. 원거리 시전 불가
7. **물 화살 (Water Arrow)**
   - 원리: *대기 수분 + 마나 압축 → 1체 직격 단발*
   - 제약: *극건조 환경에서 수분 부족 시 시전 약화*
8. **지진 (Tremor — 미세 단발)**
   - 원리: *땅속에서 마나 압축 + 팽창의 *순간 반복*으로 *지면 미세 진동*
   - 제약: *대지가 단단해야 함* (모래·진흙·물 위에서는 마나 흡수로 시전 실패)
9. **광명 점화 (Light Spark)**
   - 원리: *세프 알갱이 2개의 강한 충돌 — 작은 빛 알갱이 1점 발현*
   - 제약: *없음* (모든 원소의 원형)
10. **흙 결박 (Earth Snare — 미세)**
    - 원리: *지면 마나 응축 + 발끝 압박 — 1체 발 결착*
    - 제약: *대지·바닥 접지 필요*. 공중·물 위 시전 불가

### 2써클 (1~2종 합성·0.5~1초·8종)

> *단일 원소 + 1~2종 합성 또는 단일 원소의 *반복·다발화*. 시전 *0.5~1초*. 위력 단발·다발 또는 짧은 광역.

1. **화염 화살 (Fire Arrow)**
   - 원리: *화염 발생 + 바람의 화살 합성 — 불을 화살 형태로 압축 발사*. 1써클 바람의 화살 + 1써클 화염 점화의 합성
   - 제약: *비 올 때는 시전 어려움 (화염 유지 어려움)*. 다발 발사 시 마나 빠른 소진
2. **얼음 송곳 (Ice Spike)**
   - 원리: *물 + 즉냉각 합성 — 1써클 물 화살의 *결정화 변형*
   - 제약: *대기 수분 부족 시 위력 약화*. 비·습한 환경에서 본격 위력
3. **번개 화살 (Lightning Arrow)**
   - 원리: *전기 충격의 *원거리 발사 변형 — 정전 응축 + 바람의 화살 합성*
   - 제약: *시전 거리 5~10m 한계*. 빗속에서는 *전도 분산되어 위력 약화*
4. **전기 방출 (Electric Discharge)** ★ (사용자 추가)
   - 원리: *손에서 *원거리 전기 방출 — 1써클 전기 충격의 *원거리 변형 + 마나 압축*
   - 제약: *사정 3~5m + 시전 직후 1~2초 회로 충전 필요*. 비전도성 환경에서 위력 약화
5. **광명 폭발 (Light Burst)** ★ (사용자 추가)
   - 원리: *광명 점화 + 광역 분산 합성 — 순간 밝은 빛 폭발로 *시야 차단·일시 실명 유도*
   - 제약: *반경 5~10m·지속 0.5~1초*. *시전자 본인도 시야 일시 영향 — 눈 감기 매개 필요*
6. **바람 도약 (Wind Leap)**
   - 원리: *바람 압축 + 발바닥 폭발 합성 — 자기 신체 추진 매개*
   - 제약: *지면 접지 필요*. 1회당 *반동 회복 0.5초*
7. **흙 벽 (Earth Wall)**
   - 원리: *지면 흙·먼지 입자 가열·압축으로 *일시 결정화 방벽 형성*
   - 제약: *지면 흙 풍부 필요*. 돌바닥·금속 위에서는 시전 실패
8. **마법진 결계 (소형) (Small Circle Shield)**
   - 원리: *바닥 마법진 + 마나 회전 → 반경 1~2m 일시 보호막*
   - 제약: *시전자 위치 고정*. 이동 시 결계 해체

### 3써클 (2종 합성·1초 이내·8종)

> *2종 합성의 *본격 발현*. *동시성 제어 매개 필요 없이 자기 정통 안에서 합성 가능*. 위력 *광역 단발 또는 다발 연쇄*.

> 1써클로 이관: **바람 손날** (단일 바람 압축으로 직격이라 합성 단계 아님)

1. **번개 연쇄 (Chain Lightning)**
   - 원리: *번개 화살 + 다발 전파 합성 — 1차 직격 후 3~5체 연쇄*
   - 제약: *대상 간 거리 5m 이내 + 전도 매개 (금속·물·접촉)*. 비전도성 환경에서는 연쇄 차단
2. **진공 (Vacuum)** ★ (사용자 추가)
   - 원리: *마나의 팽창을 지속 — 잠시 진공 상태로 만든다*. 광역 분사 + 공기 강제 분산의 합성
   - 제약: *반경 2~3m·지속 1~2초*. *시전자 본인도 호흡 차단 영향 — 시전 후 잠시 무호흡 부담*
3. **잔상 (Afterimage)** ★ (사용자 추가)
   - 원리: *신기루 효과 + 광명 분산 합성 — 자기 잔상 1개 생성 (이동 직후 0.5~1초 잔존)*
   - 제약: *시전자 빠른 이동 동작과 동기화 필요*. *근접 5m 이내 적에게만 효과적*
4. **화염 분사 (Flame Stream)** ★ (사용자 추가·압축 아닌 팽창 응용)
   - 원리: *화염 발생 + 광역 팽창 분사 합성 — 잠시 동안 화염이 분사*. *압축 아닌 팽창 운용으로 *지속형 화염*
   - 제약: *시전 1초 + 지속 2~3초·사정 3~5m*. *화염 분사 중 시전자 위치 고정*. 비 올 때 위력 약화
5. **얼음 결계 (Ice Wall)**
   - 원리: *얼음 송곳 + 광역 결정화 합성 — 일시 방벽 (1~2회 직격 견딤)*
   - 제약: *대기 수분 풍부 필요*. 고온 환경에서 분쇄 가속
6. **물 결계 (Water Veil)**
   - 원리: *물 화살 + 광역 분사 합성 — 보호막 + 화염 약화*
   - 제약: *시전 후 2초 지속*. 그 후 자연 분산
7. **화염 봉인 (Flame Bind)**
   - 원리: *화염 발생 + 적 좌표 고정 합성 — 1체 1~2초 동작 차단*
   - 제약: *대상이 1체*. 광역 봉인 불가
8. **흙 진동 (Earth Pulse)**
   - 원리: *지진 + 광역 확산 합성 — 반경 3~5m 미세 진동 기동 방해*
   - 제약: *단단한 대지 필요*. 진동 효과는 *대상 균형 흔들기 정도*

### 4써클 (2~3종 합성·약 2초·9종)

> *2~3종 합성 + 위력 본격*. 시전 *약 2초*. *대륙 정식 마법사 (Mage) 의 본격 기술*.

1. **화염구 (Fireball)**
   - 원리: *화염 발생 + 고열 응축 + 바람의 화살 = 3종 합성*. 손 안의 마나 회전 → 마찰 → 연소 → 응축 → 던지기의 5단계
   - 제약: *비 올 때 시전 어려움*. *주변 마나가 자기 마나보다 많으면 앤트로픽 분산으로 응축 실패*
2. **광역 화염 폭압 (Flame Burst)**
   - 원리: *화염구 + 광역 폭압 합성 — 반경 10~15m 표면 일시 가열*
   - 제약: *비·습한 환경에서 위력 30~50% 감소*. *지속 시간 짧음 (1~2초)*
3. **침습 (Water Invasion)** ★ (사용자 추가)
   - 원리: *고농축 물 + 압축 침투 + 피부 강제 침습 = 3종 합성. 상대 몸이 붓고 큰 통증 수반*
   - 제약: *대기 수분 + 대상 피부 접촉 또는 근접 1~2m 필요*. *대상이 두꺼운 갑옷·결계 보유 시 효과 차단*. *살의 매개 — 윤리적 회피 응용으로 분류*
4. **다중 잔상 (Multi Afterimage)** ★ (사용자 추가)
   - 원리: *3써클 잔상 + 얼음 거울 반사 합성 — 신기루 + 얼음 결정의 *광 굴절 매개로 *순간 여러 잔상 생성*
   - 제약: *시전 2초·지속 1~2초·대기 수분 일부 필요*. *적이 광역 시야 (열 감지·마나 감응)를 보유하면 진위 식별 가능*
5. **얼음 폭풍 (Ice Storm — 단발형)** ★ (사용자 추가·근접 단발)
   - 원리: *얼음 송곳 + 고속 회전 + 광역 분산 = 3종 합성. 작은 잔얼음이 고속 회전으로 *근접 반경 3~5m 다발 베기*
   - 제약: *대기 수분 풍부 필요*. *지속 1~2초*. 6써클 *광역 얼음 폭풍*의 *근접 단발형 원형*
6. **마나검 (Mana Blade)**
   - 원리: *체내 마나 응축 + 임시 검 형태 빚기 합성 — 일격 후 소실*
   - 제약: *시전자 손에 직접 빚어야 함*. 원거리 발사 불가
7. **동결 폭발 (Frost Burst)**

### 앤트로퍼 특전 — *동시 시전 감응 +1 정통* ★

> 본 정통 = *앤트로퍼 (특히 강 발현)의 *생리적 본격 정점*. *마법 시전 매커니즘 자체를 다르게 한다*. 상세 본질 = [`./05-앤트로퍼-내공.md`](./05-앤트로퍼-내공.md) §0a

#### 정리 (사용자 정의)

1. **기본 *+1의 동시 시전 감응*** — *앤트로퍼는 *같은 써클 일반 마법사 대비 *동시 시전 가능 마법 1종 추가 보유*. 일반 5써클 마법사 = 3종 동시 시전 / 앤트로퍼 5써클 = 4종 동시 시전 가능
2. **동시 시전 이득으로 *위력은 약하고 고수준 마법 시전 가능*** — *각 단일 시전 위력은 *일반 마법사 대비 동급 또는 약함*. *그러나 *합성 깊이가 +1단계로 격상되어 *외관 위력 1써클 격상*. 즉 *3종 합성 5써클 마법사 ≈ 앤트로퍼 4종 합성 → 6써클급 외관 위력*

#### 본작 적용 — 카엘 변종 마검사 정통

- 카엘 = *3써클 익숙 (1초 이내) + 4써클 익숙 (약 2초) + 5써클 일부 (수초)*
- **앤트로퍼 특전 +1 동시 시전 효과**:
  - *3+3 합성 + 1 (앤트로퍼) = 4종 합성 → 외관 7써클급* (단, 단일 위력은 약함)
  - *4+4 합성 + 1 (앤트로퍼) = 5종 합성 → 외관 8써클급*
  - *5+5 합성 + 1 (앤트로퍼) + 동시성 제어 아티팩트 = 6~7종 합성 → 외관 9써클급* (Ch1 P5 학살자 호칭의 *진짜 매개*)
- *카엘의 진짜 위력 등급 = 3~5써클 단일 시전*. *그러나 *동시 시전 +1 + 동시성 제어 아티팩트의 *2중 매개로 *외관 7~9써클 광역 효과를 *1초 이내 압축 시전 가능*

#### 일반 마법사가 못 따라하는 이유

- *일반 5써클 마법사 = 3종 동시 시전 한계 (자기 회로의 분리 매개)*
- *앤트로퍼 = 마법 회로 = 신체 회로 통합 → 회로 다중 운용이 *생리적으로 가능*. 자기 의식적 노력 없이도 *+1 동시 시전 자동 작동*
- *대륙 정통상 *앤트로퍼 변종 마검사가 *진짜 강한 사유*. *광역 학살 외관 위력 = 일반 마법사 합성 한계를 초과*

### 물질변환계 (Transmutation School) — *별도 분류·인간 시전 불가*

> 본작 정통: **물질변환계는 *일반 마법 (감응·배열·고정의 합성 정통)과 완전히 다른 매커니즘***. *가장 작은 입자 (세프 알갱이의 *상위 입자 단위)의 *진동수와 조합*을 이용하여 *물질의 본질을 변환*. 기본적으로 *인간이 마법을 다루며 시전하는 것은 불가능*.

#### 매커니즘 본질

- *대륙 정통상 물질변환계는 *드래곤·고대 존재의 영역*. *행커만의 본태 (블랙드래곤)가 일부 가능했던 정통*
- *세프 알갱이 = 1단계. 그 *상위 입자 = 2~3단계. 더 상위 = 4단계 (드래곤 감응 영역) + 5단계 이상 (대현자급)*
- *물질변환 시전 = 4단계 이상 입자의 *진동수 직접 조정 + 패턴 재조합*. 인간 마법사의 *감응 회로는 *1~2단계 입자까지만 인지 가능*

#### 인간이 시전 불가능한 이유

1. *체내 마나 회로의 *감응 한계 — 3단계 이상 입자 인지 매개 부재*
2. *시전 시간 = 대륙 시간 단위로 측정 불가 (수일·수년 단위)*
3. *시전 위력 = 자기 신체·자기 거처·자기 영역의 *물리적 변형 위험*

#### 본작 등장 정통

- **행커만의 마법학** — *행커만이 드래곤 본태에서 인간 모습으로 위장한 시기 학습한 결과*. *행커만이 인간에게 *공유한 마법학 = 모두 감응·배열·고정의 합성 정통* (1~9써클 인간 가능 범위). *드래곤 영역의 *물질변환은 공유 안 함*
- **드워프 비전 룬 결각** — *물질변환계의 *부분 우회 정통*. *룬 결각으로 *입자 패턴 일부 매개 가능*. 인간이 *드워프 도움으로만 사용 가능*. 카엘 Ch2 P5 의수의 *카보나이트·미스릴·아다만티움의 룬 결각 = 물질변환의 우회 결과물*

- **앤트로퍼 특전 마기 전신 운용** — *전신에 마기 흘림으로 *신체 가속·내구력·공격력 강화*

- **마법 + 검 합성**: 바람 손날·검 막은 화염·맞댄 검 전기 충격·빙판 보법·바람 도약
- **동시성 제어 아티팩트** = *3~4개 마법 압축 시전 → 외관 위력 7~8써클*
- **자기 회로 직접 격발** = 5써클 광역 마나 파동. *자해 위험 (Ch1 P5 4합)*
- **심장 회로 직접 격발** = *본래 한 번 쓰면 다음 한 시간을 살 수 없는 비기*

### 정의롭게 싸우는 믿음 (Ch1 P5 전까지)

- 카엘은 *앤트로퍼 의식 침해로 심각한 사고 저하*. *라이세린의 조작 — 카르샤가 마계 차원의 균열을 획책한다*는 정보를 *완전히 믿고* *정의롭게 싸움*
- 의식 침해 = *비뚤린 시야*. *적의 평화 사절단을 *함정으로 해석. 항복 사절을 *예방 섬멸*. 모든 적대적 해석이 *자기 안에서 정의로움으로 합리화*
- **Ch1 P5 4-4 *왕의 한마디 + 자기 희생*이 *이 사고 저하에 *첫 본격 균열을 낸다***. *5합 결투의 1·2·3·4합 = 정의의 도구 / 5합 = 균열의 빛*

## 5. 알레이언 6세 능력 정통 (사용자 너프 정합)

### 본래 등급

- **5써클 신성마법사** (대륙 신성 위계상 *대주교 직전급 + 왕가 비전 매개*)
- **소드 마스터 *바로 전단계* = 익스퍼트 정점**
- 카르샤 신성제국 = *무력 약함·주변국 의지 정통*. *왕가 본질 = 신성 권위 + 정치 + 종교 동시 정점 — 군 무력의 정점은 아님*

### 본작 Ch1 P5 시점 — 추가 너프 (호스반 강 독살 매개)

- **카르샤 광범위 중독 + 알레이언 자기 해독 거부의 결과**:
  - *전투력 = 익스퍼트 정점의 *약 절반 (소드 마스터 레벨의 반)*
  - *검기 운용 제한적* — 일반 익스퍼트 검기보다 *유지 시간 짧음·밀도 낮음*
  - *신성 마법 시전 = 시전 시간 매개로 *전투 중 운용 매우 제한적*. *5합 결투 중 사용 가능한 신성 마법 = 1~2회 부분 시전 정도*
  - *반응 속도·신체 능력 = 정상의 60~70%*

### 5합 결투의 본질

- *알레이언이 정상 상태 + 신성 마법 자유 운용이었다면 카엘은 절대 이길 수 없는 상대*
- *그러나 독 중독 + 검기 운용 제한 + 신성 마법 시전 시간 매개로 *알레이언의 본격 정점 시전은 *5합 결투 중 거의 불가능*
- **+ 알레이언 본인의 *자기 죽음 결단*** — *마지막 5합에서 *검을 거꾸로 바닥에 박고 두 손을 가슴에 모음 = 자기 희생의 정통*. *알레이언이 *자기를 막지 않은 결과로 카엘의 마나창 직격*
- 카엘 = *4써클 광역 화염 폭압 + 3써클 번개 연쇄 + 4써클 마나검 + 5써클 자기 회로 격발 + 4써클 마나창의 5합 누적 시전*. *알레이언의 너프 + 자기 희생 매개로 *카엘이 가까스로 1합 직격*

### 알레이언의 신성 마법 단편 (5합 중 사용)

- **판결의 가호 (Verdict's Grace)** — *신성 5써클급 부분 시전*. *5합 중 3합 시점에 *짧은 시전 매개로 *카엘 광역 파동을 *분산·흡수*. 본격 위력은 *독 중독으로 50% 출력*. *시전 시간 부족으로 광역 반격 불가 — 흡수·분산만 가능*
- **신성 결계 접기** (1합) — *익스퍼트 검기 + 부분 신성 결계 매개*로 카엘의 폭압을 *부분 반사*. 본격 신성 결계는 시전 시간 매개로 *접기 정도만 가능*
