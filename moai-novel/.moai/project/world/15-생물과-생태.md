# 리투니아 대륙 — 생물·생태 도감

본 문서 = 리투니아 대륙의 *마수·몬스터·자연 생물 카탈로그*. 각 종은 *서식지·생태·재료·길드 의뢰 등급·시장 가치*의 5중 매개로 정리.

본 도감의 목적 = *모험가 길드 의뢰 + 모험가 부산물 거래 + 본문 묘사의 일관성*. 본문에서 새 마수·재료 등장 시 본 문서에 sync.

---

## 1. 늪지대·습지 (Marshland)

### 1.1 검은 풀무늘대 (Black Marsh Hound)

- **외형**: 늑대 비슷한 짐승. 어깨 높이 약 80cm. 검은 털에 늪의 이끼가 한두 줄 붙어 있음. 송곳니 일곱 줄.
- **서식**: 늪지대 외곽. 무리 2~5마리. 한 마리는 풋내기가 잡을 만함. 5마리 이상은 위험.
- **생태**: 약초·식물 부패의 마기를 *후두로 흡수*하여 변이. 안면에 마기 잔류가 한 줄 있음. 사람·짐승 모두 사냥.
- **재료**: 송곳니 = 약초 가게에서 *해독제 매개* (사람 독·마수 독 양쪽). 가죽 = 비 막이 망토 안감 (방수). 발톱 = 잡화상 잡일용.
- **길드 등급**: 흑등급 단발 / 적등급 무리.
- **시장 가치**: 송곳니 한 쌍 = 동전 5잎. 가죽 한 장 = 은화 1잎.

### 1.2 검은 늪 곰 (Cave Bear of Marsh)

- **외형**: 검은 곰 비슷한 거대 짐승. 어깨 높이 약 2m. 무게 약 400~600kg. 발톱 다섯 개가 양손에 박혀 있음.
- **서식**: 늪지대 깊은 안쪽. 동굴 또는 늪의 마른 자리. 단독 또는 짝.
- **생태**: 일주일 단위로 변경 출몰. 늪의 짐승·물고기·풀무늘대 모두 사냥. 작은 풀무늘대 다섯 마리 사이즈. 마기 변이 없으나 *근력만으로 풋내기 마법 분사를 튕길 수 있음*.
- **재료**: 발톱 = 마법공학 부싯돌의 *부싯대 재료* (정점 도구). 가죽 = 겨울 외투 매개. 위 = 마수 독 해독제 매개.
- **길드 등급**: 청등급 단발 (둘이서 처리 권장).
- **시장 가치**: 발톱 한 쌍 = 은화 5잎. 가죽 한 장 = 금화 1잎. 위 = 약초 가게에서 은화 2잎.

### 1.3 갈색 늪 거미 (Brown Marsh Spider)

- **외형**: 다리 펴면 약 50cm. 갈색·이끼색 무늬. 거미줄 두 종 분비 — 한 종은 끈끈, 한 종은 단단.
- **서식**: 늪지대 풀밭. 떼 단위 (30~50마리).
- **생태**: 풀무늘대 새끼·작은 짐승 사냥. 사람 직접 공격은 드뭄 — 단 떼로 몰리면 위험.
- **재료**: 단단한 거미줄 = 약초사의 *봉합실 매개* (피부 봉합 정밀도 우수). 끈끈 거미줄 = 낚시줄·잡화. 거미 자체는 가치 없음.
- **길드 등급**: 흑등급 잡일.
- **시장 가치**: 거미줄 한 타래 = 동전 3잎. 약초사 매개 시 동전 5잎.

## 2. 산악·외곽 (Mountainous Frontier)

### 2.1 오크 정찰병 (Orc Scout)

- **외형**: 한 뼘 더 큰 인간형. 회녹색 피부. 가죽 갑옷 + 짧은 곡도. 부족 문장 없음.
- **서식**: 변경 산악 부족 외곽. 3~6마리 무리. 본대 사정 정찰 + 변경 침입 빈도 조정.
- **생태**: 본대로부터 며칠 거리 외곽 순찰. 부족 분쟁 시 첫 접촉. 마기 변이 없음 — 순수 근력·정찰 정통.
- **재료**: 가죽 = 변경 군 갑옷 *안감 매개* (저급). 곡도 = 고철로 재용해 → 마을 농기구. 부족 문장 없으면 가치 낮음.
- **길드 등급**: 흑등급 단발 / 적등급 무리 / 청등급 분쟁지 정찰.
- **시장 가치**: 가죽 한 장 = 동전 8잎. 곡도 한 자루 = 동전 2잎 (재용해 후).

### 2.2 오크 부족 전사 (Orc Tribe Warrior)

- **외형**: 정찰병보다 한 뼘 더 큼 (총 2m+). 가슴에 *부족 문장* 새김. 거대한 곡도 또는 부족 비전 무기. 안면이 *마기 부분 차폐*되어 일반 마법 분사가 튕김.
- **서식**: 변경 산악 부족 본대. 부족 1~3명 단위.
- **생태**: 부족 비전 의식을 거친 정점 전사. 안면 차폐는 *부족 의식의 마기 무신*에서 비롯. 카엘 자기식 분사가 안면에서 튕긴 정통.
- **재료**: ★ **부족 분쟁 회피 정통** — 길드에서 부족 전사 부산물 *받지 않음*. 사냥 보고만 가능. 시장 가치 0. 단 *부족 문장 한 점*은 변경 학자들이 비공식 비싼 값으로 사기도.
- **길드 등급**: 청등급 정점 / 적정 의뢰 등급 없음 — 본대 미접촉 권장.

### 2.3 와이번 (Wyvern)

- **외형**: 비행 가능한 중형 비룡. 날개 폭 약 6~8m. 비늘이 푸르스름한 청회색.
- **서식**: 외곽 산악 정점·고지대. 단독 또는 둥지 한 쌍.
- **생태**: 사람 영역에 잘 내려오지 않음. 영역 침범 시 활공 직격. 일반 의뢰 영역 아님.
- **재료**: 비늘 = 마법 결계 결각 매개 (앨더스톰·드워프 거래). 발톱 = 마도공학 결계 부싯대. 일반 길드 거래 불가 — 비공식 학자 거래.
- **길드 등급**: 백등급 (대륙 정점 모험가만).

### 2.4 트롤 (Troll)

- **외형**: 약 3m. 푸르스름한 회색 피부. 재생력 우수.
- **서식**: 변경 깊은 산. 단독 또는 짝.
- **생태**: 재생력으로 일반 검·창에 일시 부상만 입음. 불에 약함 — 화염 분사 직격으로 재생 차단 가능. 카엘 자기식 화염의 *드문 우위 매개*.
- **재료**: 가죽 = 고급 약초 보관용 자루 (재생력의 잔여로 신선도 보존). 위 = 약초사 비전 매개.
- **길드 등급**: 청등급 단독 / 적정 풋내기 회피.

### 2.5 고블린 (Goblin)

- **외형**: 키 약 1m 안팎. 작은 떼 단위. 회녹색 피부 + 가죽 누더기.
- **서식**: 변경 외곽 마을 부근. 떼 단위 (10~30마리).
- **생태**: 마을 가축·곡식 약탈. 마을 의뢰의 가장 흔한 적. 풋내기 첫 의뢰 단골.
- **재료**: 가치 낮음. 이빨 한 줄 = 잡화상 거래.
- **길드 등급**: 흑등급 잡일.

> **드래곤 둥지 영역 외곽 마수 (그린드래곤 카자르드 영역)** — 아래 2.6~2.9는 바이서스 북부 산악 *드래곤 둥지 영역*에 분포. 영역 안쪽으로 들수록 도리어 마수가 사라짐(드래곤 존재감 회피). Ch1 P7 4-7·4-8 등장.

### 2.6 케라투스 (Keratus)

- **외형**: 사람만 한 덩치. 머리에 단단한 뿔 두 개. 멧돼지를 닮은 체형에 짧고 거센 강모.
- **서식**: 드래곤 둥지 영역 외곽 산림. *무리 짓지 않음* — 단독 세력권.
- **생태**: 잡식. 뿌리·열매·작은 짐승·사체를 가리지 않음. 세력권 침범 시 뿔로 돌진. 멧돼지처럼 한 번 내달리면 방향 전환이 느려, 옆으로 흘리면 제풀에 쏠려 지나침.
- **재료**: 뿔 한 쌍 = 마도공학 손잡이·장식 매개. 강모 = 솔·붓 매개. 고기 = 야지 식용 (질김).
- **길드 등급**: 적등급 단발.
- **시장 가치**: 뿔 한 쌍 = 은화 1잎.

### 2.7 기빈 (Gibin)

- **외형**: 강아지 크기. 큰 귀, 가는 다리, 둥근 눈.
- **서식**: 둥지 영역 외곽 덤불. 보통 4~5마리 무리.
- **생태**: 겁이 많음 — 인기척에 먼저 흩어짐. *곤충류*를 먹음. 사람·큰 짐승을 공격하지 않음. 상위 포식자의 흔한 먹이.
- **재료**: 가죽 = 작은 주머니 안감. 가치 낮음.
- **길드 등급**: 흑등급 잡일.
- **시장 가치**: 가죽 한 장 = 동전 2잎.

### 2.8 검은갈퀴늑대 (Black-Rake Wolf)

- **외형**: 검은 털에 *붉은 눈*. 발톱이 갈퀴처럼 길고 굽음. 어깨 높이 약 1m.
- **서식**: 둥지 영역 외곽~중간. 무리 (5~9마리), 위계 뚜렷.
- **생태**: 영리함 — 몰이·매복·유인으로 사냥. 육식. 우두머리가 무리를 좌우로 갈라 길목을 좁히는 협공. 붉은 눈은 어둠 사냥에 적응. 사람도 사냥감으로 셈한다.
- **재료**: 가죽 = 방한 외투 (상급). 발톱 = 단검 손잡이 장식. 붉은 눈 결정 = 야간 시야 결각 매개 (비공식 학자 거래).
- **길드 등급**: 청등급 무리 / 적등급 단발.
- **시장 가치**: 가죽 한 장 = 금화 1잎. 발톱 한 쌍 = 은화 3잎.

### 2.9 호르곤 (Horgon)

- **외형**: 사람의 반만 한 길이의 거대 애벌레. 다리가 여럿. 마디마다 가시.
- **서식**: 둥지 영역 깊은 그늘·습한 바위 밑. 단독.
- **생태**: 육식. *독을 분비해 먹이를 녹여 흡수*. 느리지만, 근거리에서 마디의 가시를 곤두세워 찌르거나 사출. 가시·체액에 *마비·부식 독*. 위험 — 근접 회피 권장.
- **재료**: 독샘 = 부식·마비 독 매개 (금기에 가까운 거래). 가시 = 독침 매개. 체액 채취 시 신성 해독 필수.
- **길드 등급**: 청등급 (독 대비 필수).
- **시장 가치**: 독샘 한 점 = 은화 4잎 (비공식).

## 3. 강·해안 (Rivers and Coast)

### 3.1 강 거머리 (River Leech)

- **외형**: 약 20cm. 검붉은 색.
- **서식**: 변경 강·습지. 떼 단위.
- **생태**: 사람·짐승의 피를 흡수. 마기 함량 없음 — 단순 자연 생물. 사람 독 해독에 *역설적*으로 매개됨.
- **재료**: 약초사 매개 — 짠 즙이 사람 독 일부 중화.

### 3.2 해안 갑각수 (Coastal Carapace)

- **외형**: 큰 게 비슷. 등껍질 약 1.5m.
- **서식**: 카르샤 해안·헤븐즈 남서.
- **생태**: 야간 해변 출몰. 어부 위협.
- **재료**: 등껍질 = 갑옷 부속. 살은 식용.
- **길드 등급**: 흑등급 / 야간 야업.

## 4. 마계 잔재·금기 (Demonic Remnants)

### 4.1 흑마법 잔재 (Black Magic Residue)

- **형태**: 폐 광산·고대 의식장의 마기 응결체. 형체 없음.
- **생태**: 자기 의식 없음. 살아 있는 마기. 카엘 같은 *앤트로퍼*는 그 옆에 머무르면 *역으로 흡수*되어 잔재가 자동 해체. 일반 모험가는 차폐 결각 필요.
- **재료**: 잔재 자체 거래 불가 (금기). 처분 의뢰만 존재.
- **길드 등급**: 청등급 처분.

### 4.2 마계 잔존 슬라임 (Demon Slime)

- **외형**: 검은 점액 덩어리. 약 1m.
- **서식**: 옛 마계 균열 자리. 변경 깊은 외곽.
- **생태**: 살아 있는 자에게 닿으면 *마기 침습*. 카엘 같은 자에게는 약함 — 앤트로퍼 잔향으로 반발.
- **재료**: 점액 = 흑마법 매개 (금기 거래). 정상 길드 미취급.

## 5. 식물·약초 (Botanical)

### 5.1 마릿이 가르친 일곱 약초

분소 옆 약초 가게 마릿의 비전. 본작 1.5-6 단편.

| 약초 | 종류 | 효과 | 비고 |
|------|------|------|------|
| 회색 갈피잎 | 봉합 | 베인 자리 봉합 가속 | 일반 |
| 푸른 잔이끼 | 봉합 | 베인 자리 출혈 차단 | 일반 |
| 붉은 뿌리 | 출혈 | 출혈 정지 | 일반 |
| 노란 송이꽃 | 출혈 | 출혈 회복 | 일반 |
| 회녹색 가시풀 | 마수 독 해독 | 풀무늘대·곰 독 중화 | 늪지 채집 |
| 검은 꽃대 | 사람 독 해독 (1) | 일반 독 중화 | 닷새 외움 |
| 잿빛 잎 | 사람 독 해독 (2) | 침습 독 중화 | 닷새 외움 |
| **회청 가시 (오크 부족 독)** | 부족 독 해독 | 오크 부족 의식 독 중화 | 카엘 청등급 의뢰 후 추가 외움 |

### 5.2 변경 도로 흔한 약초 (잡일 채집)

- 마린 같은 학자의 의뢰 매개. 일반 채집.
- 카르엔·미드그레이드 외곽에서 흔히 채집.

## 6. 길드 의뢰 등급·보수 표준 (참조)

| 등급 | 표시 | 풋내기 가능 | 일당 |
|------|------|------------|------|
| 흑등급 | 검은 동판 | 풋내기 진입 | 동전 5~15잎 |
| 적등급 | 붉은 동판 | 1년 차 이상 | 동전 30~50잎 / 의뢰당 |
| 청등급 | 청색 동판 | 2~3년 차 이상 | 은화 2~5잎 / 의뢰당 |
| 은등급 | 은색 동판 | 사 년 차+ | 은화 10~20잎 / 의뢰당 |
| 금등급 | 금색 동판 | 5년+ 정점 | 금화 1~3잎 / 의뢰당 |
| 백등급 | 흰 동판 | 대륙 정점 (와이번 등) | 금화 5~20잎 / 의뢰당 |

본작 카엘 = 흑등급 → 적등급 (8개월) → 청등급 풋내기 (4개월) = 길드 1년 차.
본작 엘 = 등록 2년 차 (Ch1 P2 시점 청등급 풋내기).
