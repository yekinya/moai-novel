## Summary

엘이 떠난 후 카엘이 카르엔 모험가 길드에서 1년을 더 보내며 흑→적→청 등급으로 올라간다. **길드 인물 3인의 자기식 노하우**를 모자이크처럼 모은다 — 라젠(다섯 점 모으기 마나 운용)·도리(명치에서 시작하는 검 자세·장검 전환)·마릿(약초 일곱 종). **오크 분쟁지 청등급 의뢰**에서 정찰병 셋만 처리하고 본대 접촉 직전 이탈, 갈비뼈 2대·검 두 동강·보수 절반의 짠내 결과. 마지막 의뢰로 학자 **마린**의 약초 채집·도서 전달 동행을 받아 미드그레이드 외곽 변경 마법사 **델란**에게 인계한다. 둘째 날 모닥불에서 마린이 정통 3단계 화염구를 시연 + 마나 운용의 응용(냉각·바람 칼날)을 가르치고, 카엘은 자기식 분사로 응답한다. 델란이 *카엘의 시전 특성 3가지(직관 1써클·짧은 시전·유연한 응용)*를 명세화한 **카르엔 사이엔 앞 추천장**을 작성하고, 봉랍 전 카엘에게 한 번 보인다. 카엘은 단독으로 셀라리아를 향한다.

## 인물 (분할 시점 정합)

- **카엘** — 18세 임박. 자기식 1단계 분사 + 안개 다섯 점 응용 + 마린에게 *마나 냉각·바람 칼날* 신규 응용 학습 시드. 갈비뼈 2대 부러진 자리 통증 잔존. 알린의 단검 → 가방 깊숙이, 새 장검 1자루 휴대.
- **노른** — 카르엔 분소장 (1.5-6 일관 등장). 다섯 닢보다 많은 빌림돈 봉투 제공 (셀라리아 도보 보급 매개).
- **라젠** (사십대 청등급 마법사·길드 12년차) — 다섯 점 모으기 노하우 양도. 1.5-6 분소 식당.
- **도리** (삼십대 적등급 검사·기사단 자퇴) — 명치 시작 검 자세 양도. 카엘 장검 전환 권유. 1.5-6 분소 뒤뜰.
- **마릿** (오십대 약초사·분소 옆 약초 가게) — 민간 약초 일곱 종 (봉합 2종·출혈 2종·마수 독 해독 1종·사람 독 해독 2종) 양도.
- **마린** (Marin, 변경 학자, 50대, 셀라리아 자퇴) — *델란의 의뢰 도서·약초 전달자* 자격으로 카엘 동행. 정통 3단계 화염구 시연 + 마나 운용 응용 (냉각·바람 칼날) 전수. 카엘 시전 특성 평가: *시전 사이 비어 있는 시간 없음·한 시전 다섯 갈래*. 익일 새벽 카르엔으로 귀로 (짐 말 마린 소유).
- **델란** (Delran, 변경 시니어 셉터, 40대 평민 출신) — 미드그레이드 외곽 평민 거처. 카르엔 사이엔의 옛 학파 동료. 카엘 시연 확인 후 카르엔 사이엔 앞 추천장 작성·봉랍 전 카엘에게 한 번 보임.

## 핵심 비트 (분할 후반부에서 새로 강화 필요)

1. **카엘의 자기식 마법 능력의 한계와 응용성 첫 명시화** — 정통 3단계 절차 시도 실패 + 자기식만 작동 + 시전 사이 빈 시간 없음 + 한 시전 다섯 갈래
2. **마나 운용의 신규 응용 학습 시드** — 마린의 *마나 회전 = 마찰 = 열* / *마나 확산 = 냉각* / *마나 충돌 = 빛* / *마나 빠른 이동 = 바람*. 카엘 *바람 칼날* 부분 구현 성공 (마린보다 작지만 더 날카로움)
3. **추천장 = Part 4 (셀라리아 진입) 매개** — 카르엔 사이엔 앞·시전 특성 3가지 명세·봉랍 전 카엘에게 한 번 보임 (v4 사용자 정합)
4. **길드 노하우 모자이크의 완성** — 라젠·도리·마릿 세 자기식 노하우가 카엘 안에서 자기 노하우로 굳음. 정통 셉터의 한 노선 학습이 아닌 *떠돌이의 모자이크 마법학*
5. **돈의 무게·생존 현실화** — 오크 보수 절반·새 장검 첫 큰돈 지출·노른 빌림돈·마린 보수 사흘분 은화 셋·미드그레이드 객점 5닢

## Tone

- **시점**: 3인칭 근접 (카엘) 유지
- **호흡**: 분할 전반부의 *짠내 + 떠돌이 막말*에서 *지식 갈증 + 응용 실험의 흥분*으로 점진 전환. 1.5-7 모닥불 학습 장면이 *Part 4 학습 5년의 예고편*
- **분량**: 7949자 (8000±200 권장)
